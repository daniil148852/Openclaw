# 🔮 Магический Шар (Magic 8-Ball)

Простое и красивое Flutter-приложение — виртуальный магический шар 8.

## Как играть

Тапни на шар или тряхни телефон — получишь случайный ответ на любой вопрос!

## Сборка APK

При пуше в `main` GitHub Actions автоматически собирает APK:

1. Зайди в **Actions** → последний воркфлоу
2. Скачай артефакт `magic-ball-apk`
3. Установи на телефон

Или собери локально:
```bash
flutter build apk --release
```

APK будет в: `build/app/outputs/flutter-apk/app-release.apk`
